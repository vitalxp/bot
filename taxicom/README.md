# Taxi Commandos

Помощник водителя Bolt / Uber / FREENOW. Оценивает каждый заказ за доли секунды, защищает процент принятия, ведёт смену и отчёты, управляется кнопками на руле.

| | |
|---|---|
| Сайт / APK | https://taxicom.app |
| API | https://api.taxicom.app |
| Пакет Android (full) | `app.taxicom.commandos` |
| Пакет Android (Lite / Play) | `app.taxicom.commandos.lite` |
| Языки UI | EN · RU · PL |

Детальные спецификации — в `/docs` репозитория. Файл `bot.py` к продукту не относится и не меняется.

## Карта экранов Android

Поток первого запуска и основные вкладки:

```
Онбординг → Вход (или офлайн) → Главная оболочка
                                    ├── Кокпит
                                    ├── Отчёты
                                    ├── Устройства
                                    └── Настройки
```

### 1. Онбординг (`OnboardingScreen`)

Три шага при первом запуске.

| Шаг | Что на экране |
|-----|----------------|
| **Приветствие** | Бренд Taxi Commandos, три тезиса: оценка заказа, кнопки руля, тихий игнор в поездке |
| **Роль устройства** | Выбор: телефон с приложениями + решения / читатель / кокпит / экран (планшет) |
| **Разрешения** | Пояснения и кнопки «Разрешить» для нужных системных настроек |

**Роли устройства**

| Роль | Назначение |
|------|------------|
| **BOTH** | Один телефон: читает карточки и принимает решения |
| **CAPTURE** | Читатель: Bolt/Uber/FREENOW на этом телефоне, решения с кокпита |
| **COCKPIT** | Кокпит: все оферы со связанных телефонов, руль, голос |
| **VIEWER** | Планшет / второй экран: дашборд и отчёты |

**Разрешения (full-сборка)**

- Чтение карточек заказов (Accessibility) — только Bolt / Uber / FREENOW
- Слушатель уведомлений — быстрее ловить новый заказ
- Оверлей поверх платформы (вердикт)
- Уведомления смены и алертов
- Исключение из энергосбережения (Samsung / Xiaomi)

В **Lite** (Google Play) Accessibility / автотап / оверлей недоступны; на шаге показывается пояснение и ссылка на полную версию с taxicom.app.

### 2. Вход и регистрация (`AuthScreen`)

| Элемент | Описание |
|---------|----------|
| E-mail + пароль | Вход или создание аккаунта (≥ 10 символов, буквы и цифры) |
| Имя | Опционально при регистрации |
| Продолжить без аккаунта | Скоринг работает офлайн; синхронизация устройств и отчёты — после входа |

Ошибки: неверный пароль, e-mail занят, слабый пароль, нет сети к api.taxicom.app.

### 3. Кокпит (`CockpitScreen`) — вкладка «Кокпит»

Главный экран смены (тёмный «ночной» UI).

| Блок | Содержание |
|------|------------|
| Шапка | Бренд + таймер смены (если смена идёт) |
| **Живой заказ** | Платформа, продукт, вердикт (БРАТЬ / НА УСМОТРЕНИЕ / МИМО), кольцо «к порогу», цена и net, zł/км и zł/ч, подача и поездка, адреса, причины, кнопки Принять / Отклонить (или Игнор в поездке) |
| Автоприём | Обратный отсчёт вето; ⏮ на руле отменяет |
| Ожидание | Пока нет карточки: поток предложений/ч и подсказка по кнопкам руля |
| Сегодня | Доход, zł/ч, принято/всего, процент принятия, ставки по платформам |
| Лента | Последние оферы дня (платформа, цена, вердикт, исход) |
| FAB | Начать / закончить смену |
| Демо | «Показать пример заказа» — прогон на 4 реальных фикстурах без платформ |

### 4. Отчёты (`ReportsScreen`) — вкладка «Отчёты»

| Элемент | Описание |
|---------|----------|
| Период | Сегодня / вчера / 7 дней |
| Сводка | Доход, zł/ч, zł/км, принятие |
| График по часам | Столбцы дохода |
| Платформы | Bolt / Uber / FREENOW: принято/оферы, сумма, % |
| Инсайты | Короткие выводы по дню |
| Прибыль | После себестоимости авто |
| Отправка | На e-mail и в Telegram (нужен вход) |

### 5. Устройства (`DevicesScreen`) — вкладка «Устройства»

Список телефонов и планшета одного аккаунта: имя, роль, платформы, online/offline. Пояснение про связку 2–3 телефонов. Без входа — кнопка войти.

### 6. Настройки (`SettingsScreen`) — вкладка «Настройки»

| Секция | Параметры |
|--------|-----------|
| **Оценка заказа** | Длинная поездка от X км, себестоимость км, вес км↔время (α), макс. подача, мин. рейтинг, политика наличных |
| **Ночь** | Интервал ночи, мин. рейтинг ночью, потолок требовательности |
| **Платформы и комиссии** | Uber «уже после комиссии» (PL по умолчанию), комиссия Uber (если карточка грязная), FREENOW, флот |
| **Решения** | Автоприём, порог × E*, окно вето, лимит авто подряд |
| **Процент принятия** | Порог «беречь показатель» |
| **Бонус+** | Доплата за поездку в окне акции |
| **Голос и руль** | TTS, короткие фразы ночью, кнопки руля |
| **Отчёты** | Привязка Telegram (`@taxicom_bot`) |
| **Аккаунт** | Вход / выход, удаление аккаунта и данных, политика, версия |

### Системные «экраны» (не Compose)

| Компонент | Где видно |
|-----------|-----------|
| Splash | Старт приложения |
| Уведомление смены | Foreground Service: вердикт / «на смене», стоп смены |
| Алерт принятия | Push при падении к 60 / 55 / 50 % |
| Медиасессия «Taxi Commandos» | На дисплее авто / BT — сейчас играет «заказ» |
| Accessibility (full) | Системные настройки спецвозможностей |
| Notification listener | Системные настройки доступа к уведомлениям |

## Функции приложения

### Перехват и разбор заказа

- Читает карточку **Bolt / Uber / FREENOW** через Accessibility (full).
- Триггер по уведомлению платформы (~на 0,5–1 с раньше отрисовки).
- Семантический парсер **без привязки к языку UI**: цена, подача, поездка, адреса, рейтинг, теги (наличные, вне радиуса, срок, эксклюзив, приоритет, отказ без штрафа).
- Локали карточек: RU / PL / EN (+ якоря кнопок на других языках).
- PL 2025+: Uber показывает сумму **уже после своей комиссии** (~27 %); повторно не вычитаем.

### Оценка (Scoring)

- Чистый доход `net` с учётом платформы и комиссии флота.
- Ставки **R_km** (с подачей) и **R_h** (с подачей).
- Индекс эффективности **E** (геометрическое среднее нормированных ставок).
- Адаптивный порог **E\*** по потоку предложений λ.
- Длинные поездки: оценка по кругу (подача + поездка + возврат).
- Ночные правила (отдельные медианы, мягче порог потока, жёстче рейтинг).
- Жёсткие правила: себестоимость, вне радиуса + долгая подача, «подача ради ничего», наличные «никогда».
- Вердикты: **Брать** / **На усмотрение** / **Пропустить**.
- Бонус+ и ценность пункта назначения (заложено в скоринге).

### Решение и автоприём

- Режим **советник** (по умолчанию) или **автоприём**.
- Авто только при высоком E, короткой подаче, хорошем рейтинге; не во время поездки; лимит подряд; окно вето.
- Исходы: принят / отклонён / **тихо проигнорирован** / истёк.
- Во время поездки невыгодный заказ → **игнор без тапа** (не портит % принятия).

### Процент принятия

- Оценка по последним оферам + якорь с экрана платформы (когда доступен).
- Игнор в поездке и «отказ не повлияет» не считаются отказом.
- Алерты при падении к **60 / 55 / 50 %**, гистерезис.
- Режим «беречь показатель» смягчает порог.

### Управление с руля (Bluetooth AVRCP)

| Кнопка | Действие |
|--------|----------|
| ⏭ Next | Принять |
| ⏮ Previous | Отклонить / игнор в поездке; во время авто — вето |
| ⏯ Play | Повторить озвучку; long-press — отмена авто |

Поддержка парка Toyota Prius / Corolla и других head unit — см. `docs/steering-wheel-control.md`, `docs/vehicle-compatibility.md`.

### Голос (TTS)

Короткая озвучка вердикта (RU/PL/EN). Ночью — ещё короче. Пример: «Uber, 26 злотых, подача 2. поездка 18. Брать.»

### Мультиустройство

Один аккаунт: 2–3 телефона (+ планшет). Читатели шлют оферы на кокпит по WebSocket (&lt; 200 мс). Решение с кокпита уходит обратно на телефон с платформой для автотапа.

### Отчёты и доставка

- Почасовые и дневные метрики, инсайты.
- Отправка на e-mail (`reports@taxicom.app`) и в Telegram `@taxicom_bot` (`/start CODE`, `/report yesterday|week`).
- Утренний автоотчёт (сервер, ~08:00 локального времени водителя).
- CSV-экспорт через API.

### События и зоны (архитектура; часть — на следующих волнах)

В `/docs` спроектированы: прилёты/суда/концерты/футбол, сурж-зоны, проверка маршрута Google с пробками, аэропорт Uber, план смены, расходы. В текущей сборке UI опирается на ядро: захват → скоринг → кокпит → отчёты → устройства → настройки.

## Запуск

### Backend

```bash
cd taxicom/backend
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
TAXICOM_SCHEDULER=0 .venv/bin/uvicorn app.main:app --reload --port 8000
.venv/bin/pytest
```

### Android

JDK 17+, Android SDK 35/36.

```bash
cd taxicom/android
echo "sdk.dir=$ANDROID_HOME" > local.properties
./gradlew :core-parser:test :core-scoring:test
./gradlew :app:assembleFullDebug :app:assembleLiteDebug
```

Debug API в эмуляторе: `http://10.0.2.2:8000` (хост-машина).

Установка на устройство / эмулятор:

```bash
adb install -r app/build/outputs/apk/full/debug/app-full-debug.apk
```

### Эмулятор (кратко)

1. Создать AVD (API 35+, x86_64 / arm64, Google APIs).
2. Запустить эмулятор, дождаться `adb devices` → `device`.
3. Поднять backend на хосте `:8000`.
4. Установить full debug APK, пройти онбординг → «Показать пример заказа» на кокпите.

Подробности по рулю, скорингу, отчётам и Play — в `/docs`.
